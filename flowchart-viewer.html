    Cara Ekspor / Impor ke Draw.io

    Draw.io mendukung impor diagram Mermaid secara native. Anda dapat mengedit shape, warna, teks, dan ukuran bebas setelah diimpor.

    1

    Salin Kode Diagram

    Pilih diagram yang Anda inginkan dari sidebar di kiri, lalu klik tombol "📋 Salin Kode untuk Draw.io".

    2

    Buka Draw.io (Web atau Desktop)

    Kunjungi https://app.diagrams.net atau buka ekstensi Draw.io di VS Code.

    3

    Buka Menu Mermaid di Draw.io

    Di navbar atas Draw.io, klik menu: Arrange (Atur) → Insert (Sisipkan) → Advanced (Tingkat Lanjut) → Mermaid.

    4

    Tempel & Sisipkan

    Paste kode yang telah disalin ke dalam kotak input Draw.io, kemudian tekan tombol Insert. Diagram siap diedit sesuka hati!

    💡

    Metode Alternatif: Drag-and-Drop SVG

    Klik tombol "💾 Unduh File SVG" di halaman ini, lalu seret (drag-and-drop) file SVG tersebut langsung ke kanvas Draw.io atau Canva!
