    Cara Ekspor & Impor ke Draw.io / Miro

    Draw.io (app.diagrams.net) mendukung impor langsung diagram Mermaid. Seluruh elemen kotak, teks, warna, dan garis konektor dapat disunting sesuka hati setelah diimpor.

    1

    Salin Kode Diagram

    Pilih diagram yang diinginkan dari menu samping kiri, lalu klik tombol "📋 Salin untuk Draw.io".

    2

    Buka Draw.io

    Kunjungi https://app.diagrams.net atau buka ekstensi Draw.io di VS Code.

    3

    Buka Menu Mermaid di Draw.io

    Klik menu atas: Arrange (Atur) → Insert (Sisipkan) → Advanced (Tingkat Lanjut) → Mermaid.

    4

    Tempel & Sisipkan

    Paste kode yang telah disalin, lalu klik tombol Insert. Diagram langsung menjadi elemen shape Draw.io yang dapat dipindahkan dan diedit bebas!

    💡

    Metode Cepat: Drag-and-Drop File SVG

    Klik tombol "💾 Unduh File SVG" di halaman ini, lalu tarik (*drag-and-drop*) file SVG langsung ke atas kanvas Draw.io atau Canva!
